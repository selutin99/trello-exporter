# Product identity

The product name is `trello-exporter` in both languages, including page titles,
the Power-Up listing, board buttons, and authorization UI supplied by the project.
Do not translate, title-case, or append a development label to the product name.
The listing explains availability separately from the name.

The generated raster icon is `src/assets/icons/trello-exporter.png`, a 144 × 144
PNG optimized for Trello's app listing. The full generated master stays outside
the repository. The existing compact SVG is retained for the board button.

The icon was created with the built-in image generation tool and resized with
macOS `sips`. Generation prompt:

> Use case: logo-brand. Asset type: square app icon for the open-source Trello
> Power-Up trello-exporter, usable at 144×144 and 32×32. A polished, original,
> beautifully simple icon combining a small kanban board with a downward export
> arrow entering an archive tray, conveying preservation of a board snapshot.
> Crisp contemporary product icon, geometric forms, restrained subtle dimensional
> shading, strong silhouette, professional open-source productivity tool. One
> centered symbol, generous 12% safe padding, no lettering or typography, no small
> details. Rich blue with a restrained teal accent, light symbol on a deep blue
> rounded square. Not the Trello logo, not an Atlassian mark, no text, no watermark,
> no mockup, no border around the image, square canvas, readable at small size.

Primary listing category: **Board utilities**. Secondary: **File management**.
Support points to this repository's Issues. Never publish private board references
or OAuth configuration in listing documentation or screenshots.
