Data handling / Обработка данных

trello-exporter · 2026-10-18

English

trello-exporter prepares JSON snapshots and ZIP archives in your browser or Trello Desktop window. The local sample preview uses synthetic data and makes no Trello API requests.

When opened as an authorized Trello Power-Up, export reads only the explicitly configured board, including its lists, cards, checklists, comments, labels, member display identities, custom fields, and attachment metadata. ZIP export downloads available Trello-uploaded files. External attachment links are not fetched. This export interface does not modify boards.

The project operates no backend receiving board content, exports, files, or tokens. Prepared exports stay in memory until downloaded or the window is closed. Downloaded files contain board content and may contain personal information; keep them private. Warnings identify unavailable content. A capture spans an interval and is not an atomic backup.

Authorization is handled by Atlassian's official Power-Up SDK. Tokens stay in Trello private plugin data and are sent only in Authorization headers to Trello. They are not included in exports, reports, or application logs. Existing OAuth grants may include workspace board read/write permissions, although export uses read-only requests.

The app may remember your language and a fixed authorization diagnostic stage in local storage. Neither value contains tokens or authorization codes. No analytics or advertising scripts are added. The official SDK is loaded from Atlassian's CDN; a configured static host and Atlassian receive ordinary network request metadata under their own policies.

Use Atlassian connected apps to revoke access. Local file deletion and OAuth revocation are separate actions. For support, use GitHub Issues with synthetic examples only.

Русский

trello-exporter собирает JSON-снимки и ZIP-архивы в браузере или окне Trello Desktop. Локальный пример использует синтетические данные и не обращается к Trello API.

При запуске из авторизованного Power-Up экспорт читает только явно настроенную доску: списки, карточки, чек-листы, комментарии, метки, отображаемые сведения об участниках, пользовательские поля и сведения о вложениях. В ZIP скачиваются доступные файлы, загруженные в Trello. Внешние ссылки не обходятся. Интерфейс экспорта не изменяет доски.

У проекта нет сервера, принимающего содержимое досок, экспорты, файлы или токены. Собранный экспорт остаётся в памяти до скачивания или закрытия окна. Скачанные файлы содержат данные доски и могут содержать личную информацию; храните их приватно. Недоступные данные перечисляются в предупреждениях. Снимок собирается за интервал времени и не является атомарной резервной копией.

Авторизацией управляет официальный Power-Up SDK Atlassian. Токены хранятся в приватных plugin data Trello и отправляются в заголовках Authorization только в Trello. В экспорт, отчёты и журналы приложения они не включаются. Существующее OAuth-разрешение может включать чтение и запись досок рабочего пространства, хотя экспорт выполняет только чтение.

Приложение может запомнить язык и фиксированный диагностический этап авторизации в локальном хранилище. Эти значения не содержат токенов и кодов авторизации. Аналитики и рекламы нет. SDK загружается из CDN Atlassian; настроенный статический хостинг и Atlassian получают обычные технические сведения о запросах согласно своим политикам.

Отозвать доступ можно в подключённых приложениях Atlassian. Удаление локальных файлов и отзыв доступа — отдельные действия. Для обратной связи используйте GitHub Issues только с синтетическими примерами.
